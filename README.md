# YES for Cville Schools

A lightweight, single-page informational website for the 2026 Charlottesville school funding referendum.

## Preview locally

Open `index.html` in a browser, or run a local static server from this directory:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Before publishing

- Confirm the election date and final ballot language.
- Confirm all financial figures, project descriptions, and exemptions.
- Replace the temporary yard-sign photograph if a final campaign image becomes available.
- Add required campaign authorization language.
- Add the final domain and social-sharing image.
